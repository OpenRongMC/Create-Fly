# Create Fly · RongMC 构建

简体中文 · [English](./README.en.md)

RongMC 使用的 Create Fabric 构建，用于动力传动、自动加工、物流、动态结构与列车。这个仓库提供发行文件和说明；Create 的完整源代码与玩法文档见上游。

## 下载与安装

- 版本 · [v6.0.9-2](https://github.com/OpenRongMC/Create-Fly/releases/tag/v6.0.9-2) (已发布)
- 下载文件 · `rongmc-create-fly-26.3-6.0.9-2.jar`
- 运行环境 · Minecraft Java 26.3, Fabric, Java 25
- Fabric 模组 ID · `create`

把发行 JAR 放入对应实例的 `mods/` 目录。双端装同一版 Create Fly。它的 Fabric ID 是 create，避免同时安装另一份提供 create 的 JAR。需要时配合同版范围的 Create Fly Ponder Fix。

## 如何验证

用水车和传动轴验证基础机械，再查看 Ponder 教程。其他 Create 扩展需要确认支持 Fly 的具体版本与 Minecraft 26.3。
