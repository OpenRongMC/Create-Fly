## 中文

本仓库发布的是 **RongMC** 对 `Create (Fly / Zurrtum)` 的 Minecraft 26.3 Fabric 移植/维护版本。

- Fabric mod id：`create`（兼容提供：`(same)`）
- 本项目部分改动由 vibecoding（AI 辅助编程）完成，并由人工审阅与测试。
- 贡献者（Contributors）：仅 [ycrrongos](https://github.com/ycrrongos)
