# Create Fly · RongMC 构建

简体中文 · [English](./README.en.md)


从转动的水轮与齿轮开始，用传动轴和机械组合搭建自动化生产线。Create 还提供传送带、移动结构和列车，Ponder 教程会在游戏中演示机构是怎样工作的。本仓提供 RongMC 所用的 26.3 Fabric 构建。

## 使用

由完整的上游 [Create Fly](https://github.com/ZurrTum/Create-Fly) 项目提供源码。遇到 Ponder 或部署器的已知崩溃，可查看 [配套补丁](https://github.com/OpenRongMC/Create-Fly-Ponder-Fix)。

## 安装

在 [GitHub Releases](https://github.com/OpenRongMC/Create-Fly/releases/tag/v6.0.9-2) 下载 **v6.0.9-2**。使用 Minecraft Java **26.3**、**Fabric** 和 **Java 25**。 将发行 JAR 放进实例的 `mods/` 目录。 双端装同一版 Create Fly。它的 Fabric ID 是 create，避免同时安装另一份提供 create 的 JAR。需要时配合同版范围的 Create Fly Ponder Fix。
